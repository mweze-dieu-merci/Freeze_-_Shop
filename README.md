# Freeze Shop

Boutique e-commerce de mode et accessoires. Première livraison : vitrine responsive et démonstrateur de parcours d'achat.

## Fonctionnalités actuelles
- Page d'accueil éditoriale responsive
- Catalogue de démonstration
- Filtres par catégorie et recherche
- Tri par prix
- Favoris visuels
- Panier interactif avec quantités et sous-total
- Formulaire newsletter de démonstration

## Lancer le projet
Aucune dépendance à installer pour cette première version.

1. Télécharger ou cloner le dépôt.
2. Ouvrir `index.html` dans un navigateur.
3. Pour un serveur local, utiliser l'extension Live Server de VS Code.

## Structure
- `index.html` : structure de la boutique
- `styles.css` : styles et responsive design
- `app.js` : catalogue et interactions côté navigateur

## Prochaines étapes
1. Intégration dans Laravel (Blade et Vite)
2. Base de données et gestion des produits
3. Authentification clients et administration
4. Commandes, stock et suivi
5. Paiements et livraison adaptés aux marchés desservis

Les produits, prix, images et interactions actuels sont des données de démonstration. Aucun paiement réel ni envoi de newsletter n'est effectué à ce stade.
